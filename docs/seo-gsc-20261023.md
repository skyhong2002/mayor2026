## 缺陷與根因

1. **`/status/` 被列入 sitemap，但頁面是 `noindex,follow`**（資料管線快照，刻意不索引）。
   `scripts/generate_seo_pages.py` 的固定路徑清單包含它，送出互相矛盾的訊號。→ 移出 sitemap，頁面維持 noindex。
2. **`lastmod` 一律是建置日**：一天建置 4 次，`/about/` 等靜態頁也每次變成當天，lastmod 不可信。
   → 候選人時間軸頁與 `/source/<id>/` 用該候選人 `latestPostAt`；首頁、目錄、光譜、議題、搜尋、訂閱、
   議題選擇器用全站最新貼文時間；`/about/` 不填 lastmod。
3. 防止回歸：`scripts/validate_public_outputs.py` 新增 `validate_sitemap`，sitemap URL 若無對應頁面、
   canonical 非自指、或帶 noindex，驗證失敗、不發布。
4. 文件：README 誤寫 `/<city>/<candidate>/` 已轉址到 `/source/<candidate>/`；實際兩者都是正式頁
   （前者是時間軸，後者是帳號清單），已更正。

候選人資料、貼文原文／引用、議題分類語意均未更動。
