# 全縣市政見比較

全臺 22 個縣市的縣市長選區，各自使用相同的並排表格。每個議題最多 4 個比較面向，少於 20 個細分問題時最多 2 個；每人最多 3 條有引用的重點。所有原始問題與引文均可在儲存格展開，不另設來源庫與資料資訊區塊。

## 候選人與來源

- 依中選會登記名冊保留全部 81 位候選人，與各選委會號次資料按縣市、姓名精確合併。沒有號次時標示待公告，不用追蹤名單取代完整選區。
- 使用已確認帳號的已收錄全文，2026 年起至快照建立日；跨平台相同文字去重並保留來源版本。
- 已確認競選官網從首頁逐一讀取可取得文字，沿同網域的政策路徑讀取全部連結，保留各層小標。未擷取圖片與影片聲音，沒有來源的候選人仍保留於比較對象選單。
- 本次從 ingestion inbox 唯讀建立私有快照，不修改、分類回寫或刪除原始社群歷史。

## 分析流程

`sky-quality` 完整閱讀所有來源片段、抽取主張、標示主張類型與直接引句；被舊分類放入「生活」的公共議題另經一次模型重新分類。程式驗證直接引句存在於所屬來源、歸屬於正確候選人。若模型打錯來源 ID，只在原批次存在逐字吻合且歸屬單一候選人的引文時修復連結，並記錄修復依據；不猜測跨候選人歸屬。細分項按原抽取小標歸組，不額外產生未檢核的細項比較結論。

`sky-quality` 再按議題將全部細分項降維並產生代表性重點，另一個請求根據引用、來源全文與日期逐人檢核。失敗時修正後重新檢核，不能跳過仍失敗的面向。主表只公開通過檢核的重點，細項仍保留直接引文。臺北沿用既有獨立檢核快照。

```sh
python3 scripts/build_national_comparisons.py --prepare
python3 scripts/build_national_comparisons.py --analyze \
  --env-file /srv/mayor2026/.env --parallel 6 --workers 5
```

`--parallel` 是同時建置的縣市數，`--workers` 是每個建置程序的 API 請求並行數。每市快取隔離在忽略的 `private/comparison-national/<city>/`，可續跑。`--city <slug>` 可單獨處理一市；不需要為續跑再次執行 `--prepare`。

## 發布

- `/compare/`：22 縣市入口。
- `/compare/<city>/`：同選區比較，頁首可切換縣市，保留議題搜尋條件、清除上一選區的候選人 ID。
- `/api/comparisons/index.json`：各選區的路徑與計數。
- `/api/comparisons/<city>.json`：完整公開快照與精簡層。
- `/api/comparison.json`：相容的臺北資料端點。

網站建置只讀版本控制中的 `data/comparisons/<city>.json.gz` 與 `<city>-facets.json.gz`，不呼叫模型。發布驗證要求全部 22 選區、完整官方名單、問題及引文完整性、精簡層雜湊與全部 HTML 錨點正確；來源缺漏或過期分析不能悄悄略過。生成頁面只放發布 stage，不 commit 回 `main`。
