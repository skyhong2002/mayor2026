# 精簡政策面向比較

比較頁改以少量政策面向排列。每類議題至多 4 個比較項目；少於 20 個細分問題的議題至多 2 個。每個候選人顯示 1–3 條有引用依據的重點，細分問題、條件與原文放在各格的「細項與原文」。

臺北首版將 999 個細分問題整理為 54 個比較項目（主表列數減少約 95%），保留 16 類議題與全部 2,349 筆主張。

不顯示「政策原頁與全部小標」「完整來源庫」「資料資訊」三個底部區塊。原始來源仍保存在資料快照與 API，每段引文連回外部原文。

## 產生方式

```sh
python3 scripts/build_comparison_facets.py --env-file /srv/mayor2026/.env
```

只讀取已完成的 `data/comparisons/taipei.json.gz`，不重新抓取、不改寫社群貼文歷史。

1. `sky-quality` 將同議題的全部問題分到少量政策面向。每個問題必須剛好出現一次。
2. `sky-quality` 依各人的引文挑出代表性重點，保留數字、對象、範圍及條件，區分承諾、成果自述和批評。
3. 另一個 `sky-quality` 請求逐列檢核所引證據；資格條件和相對年份可核對來源全文與日期，不能只依抽取的條件欄認定。不通過時依檢核意見重寫，仍失敗就停止產出。
4. 程式驗證主快照雜湊、議題與問題完整度、候選人歸屬、引用範圍、檢核旗標和面向數量；通過後以原子置換寫入 `data/comparisons/taipei-facets.json.gz`。

分組、中間結果、檢核意見與使用量快取在忽略的 `private/comparison-facets/`。正式快照保留每個面向的模型、輸入雜湊與檢核請求來源。網站建置只讀取已檢核快照，不呼叫模型；來源快照變更而精簡層未更新時，建置失敗，避免發布過期摘要。

## 互動與相容性

- 議題可複選；統計、選單與搜尋結果皆以「比較項目」計數。
- 原文搜尋會展開命中的細項與引文，清除搜尋時收回自動展開部分。
- 舊問題與引文錨點會展開所屬面向並顯示對應候選人；舊來源錨點導至其第一筆引文。
- 「只看多人有主張」依目前勾選的候選人計算。
- `/api/comparison.json` 保留細分資料，並新增 `compactComparison`；公開輸出驗證同時檢查精簡項目與全部原問題錨點。
